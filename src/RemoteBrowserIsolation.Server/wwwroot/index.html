This site is HTML mode

HTML-mode sites aren't loaded on this page anymore — they're served directly by this server's TLS-intercepting proxy to any request that passes through it. To view one:

  1. Point this browser's proxy setting (HTTP and HTTPS) at this server's proxy port (see appsettings.json "Proxy" section).
  2. Install this server's root CA certificate into the OS/browser trust store — download it from the admin console's Root CA tab (requires an admin login).
  3. Browse to the site directly in the address bar, as normal.
